二、翻译与排版原则

正文、章节标题、目录、PDF 书签、图题、自然语言代码注释，以及适用的封面、封底和图内说明均已翻译。保留原稿页数、页面尺寸、章节顺序、插图位置与原有空白页；中文在原有版面区域内重新排版，便于与英文原稿逐页对照。目录及书内页码遵循各原稿的编号方式，可能与阅读器显示的物理 PDF 页序不同。

API 名称、类名、方法名、文件名、XML 字段、代码字符串与示例数据保留原文。实际软件界面、IDE 和调试器截图保留原样，其相关图题与说明已译。英文品牌、作者名、网址、ISBN 与正式标识符亦予保留。因此仍可在译本中看到这些有技术或来源意义的英文内容。

原书示例属于 ActionScript、Flex、AIR 与 MXML 技术背景。本次完成内容翻译与排版校验，未将示例转换为其他语言，也未对历史开发环境进行编译或运行验证。作者、出版与权利说明均保留；本译本为本次任务制作的中文译稿，未取得原作者或出版社的官方审定认证。

3. 代码保真：对主书和《最佳实践》中未翻译的代码部分按非空白字符核对，分别比较 104,540 和 7,858 个字符，共 112,398 个字符；未发现差异。此项排除已翻译的自然语言注释及正文内重排的 API 名称，不表示已执行代码。

4. 导航：《ActionScript 开发者指南》包含 393 项中文 PDF 书签；《最佳实践》包含 35 项书签，目录的 33 个内部链接均与所显示页码及有效目标页一致。框架概览和海报分别有 14 项、1 项书签。原有主书链接已保留，并核对其导航结构。

5. 视觉排版：323 页均完成页面总览筛查，代码密集页、目录、封底、图示、定义列表和容易换行的区域另行放大检查。修复了中文字体显示、海报旋转、代码注释缩进、灰底标题栏、目录页码对齐、图内注释和英文单词被拆行等问题。最终检查范围内未发现未解决的缺字、正文重叠、遮挡、越界或裁切问题。

四、第二轮校对与修订

在首版完整译本的基础上，继续按英文原稿交叉核对全部主书翻译单元，并复核《最佳实践》《框架概览》与海报的自然语言说明。本轮对主书 11 个翻译单元作精度修订：

• PDF 第 27 页：明确获取和设置 EmailConfigVO 的公共访问器属于 EmailConfigProxy，避免误读为值对象自身的方法。
• PDF 第 73 页：将 StoryVO 的文件夹说明修正为“单独存放在一个文件夹中”，避免误解为每个对象各占一个文件夹。
• PDF 第 36 页：将 multiple choice fields 译为“选择字段”，避免引申为允许同时选择多个值。
• PDF 第 46、96、97、98、103、104 页共 7 处：将 word count 统一为“词数”；示例代码按空白分隔词语，API 标识符 wordCount 和 ReportWordCount 保持原样。
• PDF 第 169 页：澄清视图组件派发事件或让事件从内部冒泡出来的表述，避免把同一事件的传递误读为生成另一个事件。

海报：清除中文覆盖区域中仍可被复制或搜索的旧英文文本。修订前后以 144 dpi 渲染进行像素比较，页面外观一致；中文说明、图形、连线和技术标识符保持可读。

另将主书 2,071 项、《最佳实践》399 项译文与实际 PDF 的可提取文本逐项比对；目录点线改为标题与右对齐页码、图示 Any 简译为“任意”等预期排版差异已单独核对，未发现尚未解释的内容缺项。主书原有 451 个链接（其中目录页 342 个）及 393 个书签的目标页均已保留。

六、原文问题记录

为便于忠实对照，以下历史原文中的不一致或未完句没有擅自改写。此处页码均指阅读器中的物理 PDF 页序：

• 《最佳实践》第 6 页正文出现 listNotifications；第 28 页代码使用 listNotificationInterests。
• 《最佳实践》第 28 页正文出现复数 handleNotifications，示例代码使用单数 handleNotification。
• 《指南》第 74 页关于 UID 的正文以“秒”为单位，第 78 页注释提到“同一毫秒”；译文保留各处原意。
• 《指南》第 161、189、191、192、233 页的部分原始代码注释未写完；译文在相应位置标注原注释未完。
• 《指南》第 151 页讨论 MilieuProxy 时，原文分别提到 CastVO 与编辑 Cast；同节代码及上下文实际指向 MilieuVO 与 Milieu。译本保留原文，并在此记录该不一致。
• 《指南》第 173 页构造函数注释提到 StoryChooser，但实际参数类型为 Chooser；此差异来自原书。
• 《指南》第 194 页添加章、场景的职责说明写 getChapter()／getScene()，而第 195–196 页代码调用 getNewChapter()／getNewScene()。译本保留两处原样，实际实现应结合代码阅读。
• 《框架概览与 UML 图解》第 3 页的 Controller.getInstance 返回类型原印为 IView；第 7、13 页的 getProxyName 返回类型原印为 IProxy。图中签名保留原稿，实际使用时应以所采用实现的接口定义为准。
