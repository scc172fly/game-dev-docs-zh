RESOURCE IDS / 原版资源标识

persistentId、DBID 与 XDB 路径不是一回事

同一个资源可能同时拥有游戏逻辑 ID、XDB 文件路径和引用 GUID。查询技能时优先展示 persistentId；没有该字段的资源不伪造 ID。

字段 / 类型英文全称中文解释使用边界
persistentIdPersistent ID稳定资源 ID，例如 healer、Healer_A1。英雄与 Talent 类型中有该字段；是字符串，不限于数字 ID。
DBID / idDatabase Resource GUID资源引用 GUIDXDB 节点引用中的 GUID，不等于 persistentId。
XDB pathResource Path原版配置文件路径用于定位原始资源；路径文件名不一定等于游戏显示 ID。
TALKITTalentKit天赋套装资源DBTalent.cs 中 TalentKit 包含 talents 列表，未定义 persistentId；本站用 XDB 路径识别。
Hero.idstring英雄资源中的另一项字符串索引字段。它与 BaseHero.persistentId 同时存在，不能把字段名相同或不同误认为数值 ID。原版 DBHero.cs：Hero 类定义 id 字段。
askIdinteger语音 / Ask 响应索引：0 表示未设置，1 对应 A1 等。它不是英雄或技能的全局唯一 ID。原版 DBTalent.cs：askId 注释说明 0 - not set, 1 - A1, etc.
TypeIdinteger / hex资源类型的类标识，用于识别资源类型，不是某个英雄或技能实例的 ID。C# 资源类型定义中的 TypeId 特性。
本站编号integer-like string例如 0001_绘阵炼金术中的 0001，是本站目录排序号，方便文件排序，不是原版 ID。Prime World 中文资料站自编目录。

已核验示例：治疗师英雄 XDB 的 persistentId 为 healer；治疗天赋 XDB 的 persistentId 为 Healer_A1。两个 ID 大小写不同，不能自行统一大小写。

因此，提示框中显示 alchemist、Alchemist_A0 这样的字符串是原版字段本身的写法，并非本站把数字 ID 改成了字符串。若某资源没有 persistentId（例如 TalentKit），本站显示资源类型和 XDB 路径，不会补造数字 ID。

源码字段定义：DBHero.cs · DBTalent.cs · DBAbility.cs

FORMULA VARIABLES / 公式变量

截图中常见的英文变量是什么意思？

以下是资料页中的表达式变量或逻辑占位符，不一定是 Nival C# 类里的字段名；必须结合所在公式和数据来源理解。

变量 / 写法中文解释使用边界
P_arena竞技模式最终属性结果表示统一竞技规则下的计算结果，不是一种单独资源，也不是账号永久属性。
F(...)计算函数占位写法“由括号中的输入计算”的函数记号；它本身没有固定的乘除关系，必须看具体定义。
hero当前英雄及其标准基础属性具体包含哪些属性取决于该段数据结构，不应把所有英雄数据字段都假定为同一集合。
learned_talents本局实际已经学习 / 点亮的天赋不是战前配置盘中所有候选天赋；只代表本场已经激活的内容。
standard_refinement竞技统一强化基准指模式统一采用的标准强化值，不读取账号长期养成高低。
match_rules当前对局模式与规则配置例如模式覆盖、规则开关和该局参数；不同模式可使用不同配置。
in_match_state对局内动态状态血量、增益、等级、场地状态等随战斗变化的变量。

CROWD CONTROL / CC

控制效果（Crowd Control）

限制敌方移动、普通攻击、施法或行为选择。CC 是技能效果类别，不是单一底层状态类。

英文名称中文名称效果说明
Stun击晕 / 眩晕通常会打断目标行动并限制移动、普通攻击和施法；具体哪些行为被禁止，以该技能的状态配置为准。
Silence沉默禁止使用技能或能力；不等于缴械，普通攻击通常仍可进行，具体看其他状态。
Disarm缴械禁止普通攻击；不代表所有技能都不能使用。
Root定身 / 缠绕限制移动；目标是否仍能普通攻击或施法，取决于具体状态。
Slow减速降低移动速度；也可能有攻速或其他速度类变体，不能一概而论。
Sleep睡眠使目标进入睡眠或失能状态；受伤是否打断、能否提前解除要看配置。
Fear恐惧强制目标逃离、远离施法者或改变行动方向。
Panic恐慌强制目标进入特定行为状态；具体移动和攻击规则以实现为准。
Taunt嘲讽迫使目标优先攻击指定对象或施加仇恨行为约束。
Blind致盲干扰视野、命中或攻击能力；具体影响范围依技能实现而定。
Hex妖术 / 变形改变目标形态或限制部分行动能力；不应默认等同于沉默或击晕。

通用游戏术语说明：具体技能可能组合多个状态与作用器；最终行为、持续时间、可驱散性和免疫规则以对应 Nival 技能及状态配置为准。

DEBUFF / NEGATIVE EFFECTS

负面效果（Debuff）

削弱敌方属性或能力；Debuff 不一定会限制目标行动。

英文名称中文名称效果说明
Armor Reduction护甲降低降低目标的物理防御能力。
Magic Resistance Reduction魔抗降低降低目标的能量 / 法术防御能力。
Attack Speed Reduction攻速降低降低目标的攻击速度。
Damage Reduction伤害降低降低目标造成的伤害；注意它与“目标受到伤害降低”不是同一方向。
Vulnerability易伤提高目标受到的伤害，可能只对特定伤害类型生效。
Healing Reduction治疗降低降低目标受到的治疗或恢复效果。
Poison中毒在一段时间内持续造成伤害。
Burn燃烧在一段时间内持续造成伤害，可能附带额外效果。

通用游戏术语说明：具体技能可能组合多个状态与作用器；最终行为、持续时间、可驱散性和免疫规则以对应 Nival 技能及状态配置为准。

BUFF / POSITIVE EFFECTS

增益效果（Buff）

增强自身或友方单位的属性、生存、速度或行动能力。

英文名称中文名称效果说明
Attack Speed Increase攻速提升提高自身或友方单位的攻击速度。
Movement Speed Increase移速提升提高自身或友方单位的移动速度。
Damage Increase伤害提升提高造成的伤害，具体适用范围以效果配置为准。
Armor Increase护甲提升提高物理防御能力。
Shield护盾吸收一定数量的伤害；需区分普通护盾、标准护盾和特殊事件处理。
Immunity免疫免疫指定类型的控制或状态，不一定免疫所有伤害。
Invulnerability无敌在指定时间或条件下免受伤害；与免疫控制不是同一个概念。
Stealth隐身降低被敌方发现或选中的能力；侦测规则取决于游戏实现。

通用游戏术语说明：具体技能可能组合多个状态与作用器；最终行为、持续时间、可驱散性和免疫规则以对应 Nival 技能及状态配置为准。

OTHER SKILL EFFECTS

其他技能效果

伤害模型、位移、驱散、召唤和空间移动等效果类别。

英文名称中文名称效果说明
DoT (Damage over Time)持续伤害在一段时间内按间隔多次造成伤害，而不是一次性爆发。
HoT (Heal over Time)持续治疗在一段时间内按间隔持续恢复生命。
Knockback击退强制改变目标位置，将其推离原来的位置。
Knockup击飞将目标抬离地面或强制进入空中位移状态；与击退的运动表现不同。
Dispel驱散移除满足条件的增益或负面状态；可驱散范围由状态优先级和规则决定。
Lifesteal吸血 / 生命偷取根据攻击或伤害结算恢复生命；要区分理论伤害与实际扣血。
Summon召唤创建或召出单位协助战斗；召唤物可能拥有独立属性和持续条件。
Teleport传送把英雄或单位转移到指定位置；可能有施法准备、目标点或落点限制。

通用游戏术语说明：具体技能可能组合多个状态与作用器；最终行为、持续时间、可驱散性和免疫规则以对应 Nival 技能及状态配置为准。

TOOLTIP / 使用方式

如何查看英雄、技能与套装的悬停资料

DESKTOP / 桌面端

鼠标悬停

只需把鼠标放在英雄头像、技能图标、天赋图标或套装部件图标上；卡片空白区和普通文字不会误触。提示框优先出现在图标右侧，靠近屏幕边缘时自动翻转。

MOBILE / 手机端

长按图标

长按图标约半秒显示提示框；手指滑动页面会取消触发。提示框会保留，点击外部区域关闭。

DATA / 数据边界

原版字段优先

优先展示 persistentId、原版技能描述、参数摘要和 XDB 来源。TalentKit 没有 persistentId 字段时展示资源路径，不伪造 ID。

本版本覆盖 64 名英雄、1,605 项天赋 / 技能资源和 60 个 TalentKit。战场消耗品的独立条目数据尚未完整整理，因此不会为缺少详情页的道具虚构悬停信息。
