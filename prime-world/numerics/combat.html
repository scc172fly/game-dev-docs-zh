MATHEMATICAL MODEL / 数学公式

物理／法术防御的原始转换

B = 0.00536 × (S + 0.3W) − 0.2； M = 0.00536 × (W + 0.3S) − 0.2

中文公式

物理防御比例 = 0.00536 ×（坚韧 + 0.3 × 意志）− 0.2
魔法防御比例 = 0.00536 ×（意志 + 0.3 × 坚韧）− 0.2
符号中文含义
B物理防御比例量
M魔法防御比例量
S坚韧 Stamina
W意志 Will
代入计算
  1. 坚韧和意志都为 50 时，两项防御比例均为 0.00536 ×（50 + 0.3 × 50）− 0.2 = 0.1484。

后续还要扣除穿透、技能防御、钳制和其他减伤；不是所有伤害直接减14.84%。

MATHEMATICAL MODEL / 数学公式

正常单护盾伤害结算的实例

DHP = max(0, Draw × (1 − R/100) × Fdef − Shield)

中文公式
实际扣血 = 取较大值（0，原始伤害 ×〔1 − 额外类型减伤百分点 ÷ 100〕× 防御与穿透乘数 − 护盾吸收量）

符号中文含义
D_raw伤害进入该普通通道前的原始值
R该类伤害额外减免百分点
F_def防御与穿透合成乘数
Shield此事件被一个标准护盾吸收的量
代入计算
  1. 输入：原始100，坚韧=意志=50，穿透=0，类型减免=10%，盾=30。
  2. 防御乘数：1−0.1484=0.8516。
  3. 类型减免及防御：100×0.9×0.8516=76.644。
  4. 剩余扣血：76.644−30=46.644。

仅对应普通伤害 + 一个标准护盾；忽略防御、纯粹伤害、多盾次序和特殊状态要另按具体分支。

MATHEMATICAL MODEL / 数学公式

普通攻速（次／秒）

APS = max(0.01, min(0.00365×AS + 0.49, 2))

中文公式
每秒攻击次数 = 取较大值（0.01，取较小值〔0.00365 × 攻速点数 + 0.49，2〕）

符号中文含义
AS攻击速度属性
APS每秒攻击次数
代入计算
  1. 攻击速度 AS=200：APS=0.00365×200+0.49=1.22次/秒。
  2. 理论攻击周期：1÷1.22≈0.8197秒。

显式攻频覆盖分支不受普通 2/s 上限；前摇、动画和弹道另外计算。

MATHEMATICAL MODEL / 数学公式

暴击概率

D′ = D − 0.25×max(0, D−500)； C = clamp(90.9D′/(D′+128) − 28 + Bonus, 0, 100)%

中文公式
有效灵巧 = 灵巧 − 0.25 × 取较大值（0，灵巧 − 500）
暴击率（%）= 把 90.9 × 有效灵巧 ÷（有效灵巧 + 128）− 28 + 暴击率加成限制在 0 到 100

符号中文含义
D灵巧 Dexterity
D′超过500后压缩的灵巧值
Bonus额外暴击百分点
代入计算
  1. 灵巧200、额外暴击0：C=90.9×200÷328−28≈27.4268%。

只对带“可以暴击”标志的伤害生效，不能默认所有技能均暴击。

MATHEMATICAL MODEL / 数学公式

受治疗与上限

Healeffective = min(MaxHP − HP, A×(1+HealingScale) + HealingBias)

中文公式
实际治疗量 = 取较小值（最大生命 − 当前生命，原始治疗量 ×〔1 + 治疗倍率修正〕+ 治疗固定修正）

符号中文含义
A技能直接计算的基础治疗量
MaxHP−HP缺失生命
HealingScale / HealingBias比例与固定恢复修正
代入计算
  1. HP=700、最大1000、A=250、比例加成0.2、固定加10：理论310。
  2. 实际缺300生命，因此最终治疗300，多余10溢出。

禁疗、忽略修正及负数治疗等特殊分支另论。
